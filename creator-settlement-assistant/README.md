# 达人结算智能助手

一个在 Windows 本地运行的结算小工具，把原始明细整理成核对表、打款表、调差表和异常报告。当前版本：**v1.3.6**。

## 能做什么

- 同任务、同单价合并结算日期，支持中间没有数据的日期。
- 核对表填写一口价，按任务合计同步到调差表；实际结算支持负数。
- 自动调差：逐条计算“转化数 × 单价 − 原表打款金额”，再合并相同任务ID。0元打款也计入差额。
- 调差线上成本可以人工修改，底部显示全表总金额；筛选后另外显示当前记录小计。
- 表格支持复制、多行多列粘贴、自动补行、整行整列选择、新增、删除、排序、筛选和查找。
- 支持最近50步撤销、重做；保存后可以选择立即打开表格。
- 收款资料保存在本地，可以重复使用；团长和达人金额可单独录入。

## 运行环境

Windows 10/11，.NET Framework 4.8。编辑和导出不依赖安装版 Excel；打开导出的表格需要 Excel、WPS 或其他表格软件。

## 编译和运行

下载并解压源码，在项目目录打开 PowerShell，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\source\build.ps1
```

编译成功后，项目目录会出现 `达人结算智能助手.exe`。双击运行，并保留同目录的 `达人结算智能助手.exe.config`，用于 Windows 高清缩放。

第一次保存收款资料时，程序会自动建立本地 `data` 文件夹。本源码包没有收款资料。

## 使用顺序

上传原始 `.xlsx` 明细 → 左侧选择表格 → 填写或修改 → 导出。

导入文件需要有任务ID、结算日期、任务名称、任务类型、转化数、单价、打款金额等表头。请使用表头清晰、金额为有效数字的明细。

| 操作 | 用法 |
| --- | --- |
| 复制、粘贴 | 选格子后按 Ctrl+C / Ctrl+V；支持多行多列 |
| 选择整行或整列 | 点左侧行号或上方列名 |
| 清空、向下填充 | Delete / Ctrl+D |
| 撤销、重做 | Ctrl+Z / Ctrl+Y |
| 排序 | 点该列格子，右键选择升序或降序 |
| 同步一口价 | 核对表填写后，点“同步至调差” |

核对表的打款金额、实际打款由程序计算，不能直接覆盖。重新同步会按对应规则重填线上成本。重新上传或切换工作表会清空当前预览和历史，请先导出保存。

## 测试

在项目目录执行以下命令，结果目录必须是新的空文件夹：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\source\test.ps1 -ResultDirectory "$env:TEMP\CreatorSettlementTests"
```

如果该目录已存在且有内容，请换一个新名字。测试在独立目录使用演示资料，不需要你的业务明细。

本整理版本已编译通过，276项演示测试通过。测试覆盖金额计算、导出、负数调差、复制粘贴、增删、撤销重做、总金额和缩放布局。125%在实际DPI环境验证，150%通过布局模拟检查。

## 文件说明

- `source/`：应用代码、编译脚本和测试代码。
- `source/templates/`：导出所需模板，已去掉个人作者信息。
- `达人结算智能助手.exe.config`：高清缩放配置。
- `.gitignore`：排除本地收款资料、生成的软件、测试结果和业务表格。
- `CHANGELOG.md`：版本变化。

演示测试中的姓名、账号等为测试占位值，请勿作为真实收款信息使用。没有附带真实结算明细、收款记录、业务截图或编译好的软件。
